What to do about it

    CRM data quality

    Records flagged by sql/12_crm_data_quality.sql.

      All companies, people and figures are synthetic, generated by scripts/generate_data.py with a fixed seed. The same metrics are produced in SQL (sql/) and rebuilt in Tableau (docs/tableau-guide.md).

      Use your own CRM export

      Export Opportunities, Users, Leads and Opportunity History from Salesforce (or any CRM) into data/ with the column names in sql/00_schema.sql, then run python scripts/run_analysis.py and python scripts/build_dashboard.py.
